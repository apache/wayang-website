Apache Wayang is developed in the open on GitHub. Each repository is also available from the Apache Software Foundation's GitBox service; both are kept in sync, and contributions are made through pull requests on GitHub.

## Source code

| Repository | What it contains | GitHub | ASF GitBox |
|---|---|---|---|
| **wayang** | The Wayang source code: core, optimizer, platforms, APIs and Javadoc | [apache/wayang](https://github.com/apache/wayang) | [wayang.git](https://gitbox.apache.org/repos/asf/wayang.git) |
| **wayang-website** | This website: documentation, guides and blog posts | [apache/wayang-website](https://github.com/apache/wayang-website) | [wayang-website.git](https://gitbox.apache.org/repos/asf/wayang-website.git) |

To get the source code:

```
git clone https://github.com/apache/wayang.git
```

See [Compiling Apache Wayang](/docs/guide/installation) for how to build it, and [How to contribute](/docs/community/contribute) before opening a pull request.

## Issues, bugs and features

If you have a specific bug to report or feature request, please open an issue on [GitHub](https://github.com/apache/wayang/issues). Before creating a new one, search the existing issues to check whether it has already been reported.

The website repository does not have its own issue tracker, so please report problems with the documentation or website in the same place, or open a pull request with the fix directly.
