Join the Community

Apache Wayang is built in the open by researchers, engineers, and students from universities and companies around the world. Whether you want to ask a question, report a bug, share how you use Wayang, or write code, you are welcome here, and no contribution is too small.

You don't need to write code to contribute. Improving documentation, spreading the word on social media, giving talks, answering questions, and testing releases are all real contributions to Wayang, and they count just as much in the Apache way.

Every contribution counts, not just code​

Open source projects need much more than code to thrive. Pick whatever matches your skills and interests; most of these don't involve the codebase at all.

Documentation

Fix a typo, clarify a confusing guide, write a tutorial, or add an example. Good docs are often the most impactful contribution, and this website is open source too.

Your first pull request​

If you want to change code or documentation, most contributors follow roughly these steps. You don't need permission to start, but saying hello first helps us point you in the right direction.

  1. 1

    Introduce yourself

    Send a short email to dev@wayang.apache.org saying who you are and what you are interested in. For larger changes, describe your plan there before you start coding so others can give early feedback.

  2. 2

    Set up your environment

    Fork apache/wayang, build it locally with the installation guide, and get familiar with the codebase through Developing in Wayang.

  3. 3

    Pick something to work on

    Choose an open issue, fix a bug you ran into, or improve the documentation. Comment on the issue so others know you are on it.

  4. 4

    Open a pull request

    Make sure the build and tests pass, then open a PR against main. Read the contribution guide and, if you use AI tools, our AI tooling policy.

  5. 5

    Iterate with reviewers

    A committer will review your PR. Address the comments, and once it is approved it gets merged. Welcome aboard!

Grow with the project​

Apache projects run on merit: people who contribute steadily earn more responsibility.

Become a committer

Committers have write access to the repositories. The PMC invites people with sustained contributions of any kind, including documentation, community building, and advocacy, not only code.

What we look for →

Join the PMC

The Project Management Committee oversees releases, votes on new committers, and keeps the project healthy. Active committers are invited over time.

Still have questions?​

Write to dev@wayang.apache.org. Messages from non-subscribers are held for moderation, so subscribing first gets your email through faster and makes sure you see the replies. For quick chats you can also ask on dev@ for an invitation to #wayang on the ASF Slack. If you aren't sure where something belongs, the mailing list is always the right place to ask.
