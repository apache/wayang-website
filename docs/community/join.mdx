Apache Wayang is built in the open by researchers, engineers, and students from universities and companies around the world. Whether you want to ask a question, report a bug, share how you use Wayang, or write code, you are welcome here, and no contribution is too small.

**You don't need to write code to contribute.** Improving documentation, spreading the word on social media, giving talks, answering questions, and testing releases are all real contributions to Wayang, and they count just as much in the Apache way.

## Your first pull request

If you want to change code or documentation, most contributors follow roughly these steps. You don't need permission to start, but saying hello first helps us point you in the right direction.

<Steps
  steps={[
    {
      title: 'Introduce yourself',
      body: (
        <p>
          Send a short email to <a href="mailto:dev@wayang.apache.org">dev@wayang.apache.org</a>{' '}
          saying who you are and what you are interested in. For larger changes, describe your plan
          there before you start coding so others can give early feedback.
        </p>
      ),
    },
    {
      title: 'Set up your environment',
      body: (
        <p>
          Fork <a href="https://github.com/apache/wayang">apache/wayang</a>, build it locally with the{' '}
          <Link to="/docs/guide/installation">installation guide</Link>, and get familiar with the
          codebase through <Link to="/docs/guide/developing-in-wayang">Developing in Wayang</Link>.
        </p>
      ),
    },
    {
      title: 'Pick something to work on',
      body: (
        <p>
          Choose an <a href="https://github.com/apache/wayang/issues">open issue</a>, fix a bug you
          ran into, or improve the documentation. Comment on the issue so others know you are on it.
        </p>
      ),
    },
    {
      title: 'Open a pull request',
      body: (
        <p>
          Make sure the build and tests pass, then open a PR against <code>main</code>. Read the{' '}
          <Link to="/docs/community/contribute">contribution guide</Link> and, if you use AI tools, our{' '}
          <Link to="/docs/community/ai-tooling-policy">AI tooling policy</Link>.
        </p>
      ),
    },
    {
      title: 'Iterate with reviewers',
      body: (
        <p>
          A committer will review your PR. Address the comments, and once it is approved it gets
          merged. Welcome aboard!
        </p>
      ),
    },
  ]}
/>

## Still have questions?

<Callout>
  <p>
    Write to <a href="mailto:dev@wayang.apache.org">dev@wayang.apache.org</a>. Messages from
    non-subscribers are held for moderation, so subscribing first gets your email through faster and
    makes sure you see the replies. For quick chats you can
    also ask on dev@ for an invitation to <code>#wayang</code> on the ASF Slack. If you aren't sure where something
    belongs, the mailing list is always the right place to ask.
  </p>
</Callout>
